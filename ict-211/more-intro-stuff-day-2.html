DEFINE VIRTUALIZATION

. The ability to enable multiple operating system (OS) instances to execute simultaneously on a single physical system.

· Allows for multiple virtual machines to run on a single host (aka a single node).

. Each virtual machine runs independently from one another and behaves like an independent computer or server.

. The OS installed on a virtual machine only has accessed to its virtualized resources (ie CPU, Memory, Storage, Network) - No direct access to the physical resource of the host.

. Most modern Operating Systems are "Enlightened" to virtualization and "understand" virtualized hardware (since Server 2012 and Windows 8)

Enlightened OS’s

the term “Enlightened” is for systems that are made to be virtualized. the OS assumes that it is running on virtualized hardware.

HYPERVISORS AND TYPES OF HYPERVISORS

. A Hypervisor is the software layer on a physical host that coordinates virtual machines

. A Hypervisor manages virtual machines and is responsible for allocating resources to each virtual machine

. The Hypervisor is ultimately what makes virtualization possible

. There are two types of Hypervisor: Type 1 and Type 2

TYPE 1 HYPERVISOR

  • Also known as the "Bare Metal Hypervisor"
  • Type 1 Hypervisor is installed directly on the physical host
  • Has direct access to the physical resources of the physical host which then allocates the available resources to the virtual machines
  • Hypervisor loads (boots) first, before the Operating System
  • Administrators have the ability to create clusters with many Type 1 Hypervisors (but not all)

TYPE 2 HYPERVISOR

  • Also known as "Hosted Hypervisor"
  • Type 2 Hypervisor is installed on top of the host Operating System (ie Windows 10)
  • The host Operating System manages the hardware resources
  • The Type 2 Hypervisor requests the resources from the Operating System
  • Type 2 Hypervisors do not support clustering

HYPERVISORS

  • Type 1 Hypervisors have better performance compared to Type 2
  • Type 1 Hypervisors have direct access to hardware resources!
  • Type 2 Hypervisors need to request resources from the OS first, the OS then accesses the hardware resources
  • Hyper-V is Type 1

HYPER-V

  • Hyper-V is a Type 1 Hypervisor!
  • Can be confusing because on Windows 10 / 11 it's a Feature that's enabled from the Control Panel
  • Can be confusing because on Server 2016/2019/2022 it's enabled as a Server Role
  • Hyper-V Manager "appears" to look like an application, but this is what an administrator uses to create/manage VMs
  • Hyper-V is the Virtual Machine Manager
