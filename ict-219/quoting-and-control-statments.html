Quoting and control statments

Glob character or wild cards

  • Include
    • Asterisk * -- > anything/wildcard
    • Question mark ? -- > any character
    • Brackets [ ] -- > specific character
  • For file manipulation, like matching pattern

Quoting

  • Three types of quotes
    • Double quotes "
    • Single quotes ‘
    • Backquotes `
  • Backslash \
  • Let the system know how the information to be treated

Double quotes

  • Inside double quotes, wild cards will be treated as a symbol or as a single string.
    • ryder@le-server:/$echo "The wild cards are *, ? and []"
      • The wild cards are *, ? and []
    • ryder@le-server:/$ echo *
      • test test.sh test.txt update.sh
    • ryder@le-server:/$ echo "\*"
      • *
    • ryder@le-server:/$ echo [D - P] *
      • [D - P] bin boot dev etc home initrd.img initrd.img.old lib lib64 lost+found media mnt opt proc root run sbin srv sys tmp usr var vmlinuz vmlinuz.old
  • Variables
    • Variable with $var in "" means the value of variable.
    • echo "The system path are $PATH" –works like var in “” in #PowerShell
    • Can't show $ character in double quote statement

Single quotes

  • Prevent shell interpret special character, including
    • Globs
    • Variables
    • Command substitution
  • Compare
    • echo The price is $200
    • echo 'The price is $200'
Summary

Single Quotes are like a literal string.

Backslash

  • For a statement need different interpretation of character
  • Character after \ will not be interpreted
  • Compare
    • echo "$USERNAME paid $500 for a laptop"
    • echo '$USERNAME paid $500 for a laptop'
    • echo "$USERNAME paid $500 for a laptop"
Summary

The Backslash ( \ ) is an escape character.

Backquotes (Command substitution)

  • Words inside backquotes interpreted as a command
  • Compare
    • echo Date Printed: date
      • echo Date Printed: date
    • echo Date Printed: `date`
      • Date Printed: Fri 02 Oct 2026 10:35:16 AM PDT
Summary

It tells the terminal to treat this part of a string as a command.

Control statements

  • Control statements use following characters
    • Semicolon ;
    • Double Ampersand &&
    • Double Pipe ||

Semicolon ;

  • Run multiple command in one line
  • Example
    • echo first; echo second; echo third;
first
second
third

Double Ampersand &&

  • Act like logic
  • Format
    • command1 && command2
  • Run the second command if first command is successful
  • Compare

Command:

Is ~ && echo ok

Output:

ryder@le-server:/$ ls ~ && echo ok
test  test.sh  test.txt  update.sh
ok

Command:

ls ~/fake && echo ok

Output:

ls: cannot access '/home/ryder/fake': No such file or directory

Double Pipe | |

  • Act like logic
  • Format
    • command1 || command2
  • Run the second command if first command is failed
  • Compare

Command:

ls ~ || echo failed

Output:

ryder@le-server:/$ ls ~ || echo failed
test  test.sh  test.txt  update.sh

Command:

ls ~/fake || echo failed

Output:

ryder@le-server:/$ ls ~/fake || echo failed
ls: cannot access '/home/ryder/fake': No such file or directory
failed
