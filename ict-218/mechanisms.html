Mechanisms

Key Concepts

1. Security Threat Landscape

Key Ideas

  • Average data breach cost exceeds $10 million for U.S. organizations.
  • Attackers often remain undetected for months.
  • Most breaches originate from compromised credentials.
  • Social engineering remains one of the most effective attack vectors.

2. Microsoft Defender Antivirus

Purpose

Built-in anti-malware and antivirus protection included with Windows Server 2025.

Features

  • Enabled by default.
  • Real-time protection.
  • Virus and threat protection.
  • Automatic updates.
  • Tight integration with Windows.

Administrative Functions

  • Enable/disable real-time protection.
  • Manage scans.
  • Update threat definitions.
  • Monitor security status.
Updating

When updating on a server you must evaluate impact and schedule downtime.

3. Microsoft Defender for Endpoint (EDR)

Purpose

Enterprise Endpoint Detection and Response (EDR) platform.

Capabilities

  • Behavioral analysis
  • Threat detection
  • Incident investigation
  • Automated remediation
  • Centralized management

Security Benefits

  • Detects advanced threats.
  • Uses cloud intelligence.
  • Shares threat intelligence across Microsoft customers.

Real-World Example

A malicious attachment received by one Microsoft customer may be automatically blocked for all others once identified.

4. Windows Defender Exploit Guard

Components

Attack Surface Reduction (ASR)
Blocks risky behaviors such as:

  • Office macros launching scripts
  • Executables from email
  • Suspicious processes

Network Protection
Uses Microsoft SmartScreen to:

  • Block malicious websites
  • Prevent communication with known attacker infrastructure
  • only in edge - not integrated on other browsers

Controlled Folder Access
Protects critical files from ransomware encryption.

Exploit Protection
Provides memory and exploit mitigations against software/ransomware attacks.

5. Windows Defender Firewall with Advanced Security (WFAS)

Purpose

Host-based firewall protection built into Windows.

Administrative Interfaces

  1. Control Panel Firewall
  2. Windows Security Firewall Settings
  3. Windows Defender Firewall with Advanced Security (WFAS)

Why WFAS Matters

Modern Windows Firewall provides:

  • Stateful inspection
  • Inbound/Outbound rules
  • IPsec integration
  • Connection Security Rules

Security matter

Network firewalls alone are not sufficient. Host-based firewalls provide an additional security layer.

6. Firewall Profiles

Domain Profile

Activated when connected to Active Directory.

Private Profile

Trusted networks such as home or office.

Public Profile

Least trusted network profile.

Important Concept

Different security rules can apply automatically based on network location.

Example

A laptop may use:
• Domain profile at work
• Private profile at home
• Public profile at an airport

7. Firewall Rule Management

Common Tasks

  • Block RDP from external interfaces
  • Allow ICMP (Ping)
  • Restrict traffic to specific subnets
  • Configure inbound/outbound rules

Best Practice

Apply firewall rules centrally through Group Policy.

8. Encryption Technologies

Why Encryption Matters

Protects:

  • Data at Rest
  • Data in Transit
Also See
  • 3 States of Data

Key Technologies

• BitLocker
• EFS
• IPsec
• Encrypted Virtual Networks

Security Objective

Prevent unauthorized access even if infrastructure or storage systems are compromised.

9. BitLocker and Virtual TPM

BitLocker

Full disk encryption technology.

Benefits
Protects:

  • Laptops
  • Servers
  • Virtual Machines

Virtual TPM (vTPM)

Allows virtual machines to:

  • Store encryption keys securely
  • Use BitLocker without physical TPM hardware
  • Must be enabled to use.

Key Concept

BitLocker protects data even if virtual hard disks are stolen or copied.

10. Shielded Virtual Machines

Purpose

Protect Hyper-V virtual machines against host-level attacks.

Security Features

  • BitLocker encryption
  • Virtual TPM
  • Host Guardian Service integration

Security example

Useful in multi-tenant or cloud environments where infrastructure administrators must not access guest data.

11. Encrypted File System (EFS)

Purpose

Encrypts individual files and folders.

Requirements

• User certificate
• PKI infrastructure

Limitation

Security depends heavily on protection of the user's credentials.

Comparison

Technology Protects
BitLocker Entire drive
EFS Selected files/folders

12. IPsec

Purpose

Encrypts network traffic.

Uses

• VPN (IKEv2)
• DirectAccess
• Internal network encryption

Policy Types

Server Policy
Requests encrypted communications.
Secure Server Policy
Requires encrypted communications.
Client Policy
Responds to encryption requests.

13. Microsoft Entra Password Protection

Purpose

Blocks weak and commonly used passwords.

Features

• Microsoft's global banned password list
• Custom banned passwords
• Integration with on-premises AD

Examples

Blocked passwords:
• Password
• Password123
• P@ssword

Security Benefit

Reduces credential compromise.

14. Fine-Grained Password Policies (FGPP)

Purpose

Apply different password policies to different users or groups.

Examples

Group Password Policy
Sales Staff Strong passwords, short expiration
Manufacturing Staff Less restrictive requirements

Key Components

• AD Administrative Center (ADAC)
• Password Settings Objects (PSOs)
• Precedence values

Security Point

Supports risk-based security controls.

15. Windows LAPS

Purpose

Automatically rotates local administrator passwords.

Benefits

• Unique password per device
• Password rotation
• Central storage
• Protection against Pass-the-Hash attacks

Storage Locations

• Active Directory
• Microsoft Entra

Key Commands

1 Update-LapsADSchema
2 Get-LapsADPassword
3 Set-LapsADPasswordExpirationTime

One of the most important identity security technologies available today.

16. Microsoft Defender for Identity

Evolution

ATA → Azure ATP → Defender for Identity

Capabilities

• Identity threat detection
• Behavioral analytics
• Lateral movement detection
• Pass-the-Ticket detection
• Credential theft detection

Uses Machine Learning

Identifies abnormal user behavior and possible compromises.

17. Security Best Practices

Least Privilege

Users should not have administrator rights.

Separate Administrative Accounts

Use:
• Standard user account
• Administrative account

Privileged Access Workstations (PAW)

Use separate computers or VMs for administrative functions.

Avoid Internet Browsing on Servers

Reduces attack surface and malware exposure.

18. Role-Based Access Control (RBAC)

Definition

Access based on job responsibilities.

Benefits

• Reduced privilege
• Better accountability
• Easier auditing

19. Just Enough Administration (JEA)

Purpose

Provide limited administrative capabilities using PowerShell.

Benefits

• Granular privileges
• Reduced attack surface
• Supports Zero Trust principles

20. RDP Security

Risks

RDP exposed to the internet is a common attack vector.

Recommendations

• Block external RDP access
• Use VPNs
• Use RD Gateway
• Restrict access via WFAS

Security Point

Changing the RDP port is obscurity, not security.

21. Disabling Weak Encryption Protocols

Deprecated Technologies

• SSL 3.0
• TLS 1.0

Secure Alternatives

• TLS 1.2
• TLS 1.3

Management Tools

• Registry
• IIS Crypto

Security Principle

Remove outdated cryptographic protocols to prevent exploitation.

Chapter Takeaways

Students should leave this chapter understanding that modern Windows security
relies on multiple layers:
22. Endpoint protection (Defender)
23. Host firewalls (WFAS)
24. Identity security (Entra Password Protection, LAPS)
25. Encryption (BitLocker, IPsec)
26. Detection and response (Defender for Endpoint, Defender for Identity)
27. Administrative hardening (RBAC, JEA, least privilege)
The overarching theme is Defense in Depth and Zero Trust, where no user, device,
or network segment is inherently trusted and security controls must exist at every
layer.
