Security controls

Learning Objectives

By the end of this lecture, students should be able to:

  • Define security controls and explain their purpose.
  • Describe the four categories of security controls.
  • Differentiate between control categories and control types.
  • Explain the six major control types using the PDDCCD framework.
  • Apply security control concepts to real-world cybersecurity scenarios.
  • Identify examples of controls used in organizations.
  • Analyze how multiple controls work together through Defense in Depth

1 Introduction to Security Controls

What Are Security Controls?

Security controls are safeguards or countermeasures that protect an organization’s:

  • Information
  • Systems
  • Networks
  • Facilities
  • Employees

The purpose of security controls is to reduce risk by:

  • Preventing attacks
  • Detecting attacks
  • Responding to incidents
  • Recovering from disruption

Why Are Security Controls Important?

No organization can completely eliminate risk.
Threats constantly evolve:

  • Hackers
  • Malware
  • Insider threats
    • disgruntled employee
    • bad software
  • Social engineering attacks
  • Physical theft
    Organizations implement security controls to minimize the chances of successful
    attacks and reduce the impact when incidents occur.

Defense in Depth

A common cybersecurity strategy is called Defense in Depth.

Definition

Defense in Depth means using multiple layers of security controls rather than relying on a single protection mechanism.

Example

Imagine a company protecting a file server:

Security Layer Control
Physical Locked server room
Technical Firewall
Technical Antivirus
Technical MFA
Managerial Managerial Security policy
Operational Log monitoring

If one layer fails, additional layers continue protecting the organization

Real-World Example

A user's password is stolen.

Without MFA:

  • Attacker logs in immediately.

With MFA:

  • If Passwords are compromised.
  • MFA blocks access.
  • The security team receives an alert.
    One failed control does not necessarily mean a security breach.

2. Security Control Categories

Security controls are grouped into four major categories

A. Technical Controls

Definition

Technical controls are implemented through hardware or software systems.
They automatically enforce security requirements.

Purpose

Protect digital assets using technology.

Examples

  • Firewalls
    • A firewall filters network traffic.
    • Functions:
      • Allows authorized traffic
      • Blocks unauthorized traffic
      • Monitors network communications
    • Example:
      • A firewall blocks incoming traffic from known malicious IP addresses
  • Multi-Factor Authentication (MFA)
    • MFA requires multiple forms of verification.
    • Three common factors:
      1. Something you know
        • Password
      2. Something you have
        • Smartphone
        • Smart card
      3. Something you are
        • Fingerprint
        • Facial recognition
    • Example
      • Logging into Microsoft 365 requires:
        • Username
        • Password
        • Approval through Microsoft Authenticator
  • Encryption
    • Encryption converts readable data into ciphertext.
    • this works hand in hand with the CIA Triad
    • Benefits:
      • Protects confidentiality
      • Prevents unauthorized access
      • Secures sensitive information
    • Examples:
      • HTTPS websites
      • BitLocker drive encryption
      • VPN communications
  • Antivirus and Endpoint Protection
    • Functions:
      • Detect malware
      • Block malicious programs
      • Quarantine infected files
      • Remove threats
    • Real-world Example:
      • Microsoft Defender identifies ransomware activity and isolates the affected device.

B. Managerial Controls

Definition

Managerial controls are administrative processes used to manage security programs.

Purpose

Create security governance and oversight.

Examples

  • Security Policies
    • Policies establish management's security expectations.
    • Examples:
      • Password policy
      • Remote work policy
      • Acceptable Use Policy (AUP)
    • Policies tell employees what they can and cannot do.
  • Risk Assessments
    • Organizations must identify:
      • Threats
      • Vulnerabilities
      • Potential impacts
    • Questions include:
      • What can go wrong?
      • How likely is it?
      • What would be the impact?
  • Security Awareness Training
    • Human error remains a major cause of security incidents.
    • Training helps employees:
      • Identify phishing attacks
      • Recognize suspicious behavior
      • Follow security procedures
  • Audits and Compliance Reviews
    • Audits verify:
      • Policies are followed
      • Controls are working
      • Regulatory requirements are met
    • Examples:
      • ISO 27001 audits
      • PCI-DSS assessments
      • Internal security reviews

C. Operational Controls

Definition

Operational controls are security activities performed by people during daily operations.

Purpose

Ensure security procedures are consistently followed.

Examples

  • Account Management
    • Examples:
      • Creating user accounts
      • Disabling terminated employees
      • Reviewing permissions
    • Poor account management frequently leads to unauthorized access.
      Incident Response
      When a security incident occurs:
      • Detect
      • Analyze
      • Contain
      • Eradicate
      • Recover
      Organizations develop incident response procedures before an attack occurs.
      Security Monitoring
      Security analysts continuously monitor:
      • Event logs
      • Security alerts
      • Network activity
      Example:
      Microsoft Sentinel identifying suspicious login activity.
      User Awareness Programs
      Employees learn:
      • Secure password practices
      • Email security
      • Social engineering awareness
      Users become part of the organization's security defense.

D. Physical Controls

Definition

Physical controls protect facilities, equipment, and personnel.

Purpose

Prevent unauthorized physical access.

Examples

Locks and Keys
Protect:
• Server rooms
• Data centers
• Equipment cabinets
Security Guards
Provide:
• Visible security presence
• Access verification
• Emergency response
CCTV Surveillance
Functions:
• Monitor activity
• Record evidence
• Support investigations
Fencing and Gates
Used to create secure boundaries around facilities.
Examples:
• Data centers
• Power plants
• Corporate campuses
Mantraps
A mantrap is a small, controlled entry area containing two doors.
Purpose:
• Only one person enters at a time.
• Prevents tailgating attacks.
Commonly used in:
• Data centers
• Research laboratories
• Government facilities

3. Security Control Types (PDDCCD)

Categories tell us what kind of control it is.
Types tell us what the control does.

Preventive Controls

Purpose

Stop attacks before they occur.

Examples

• MFA
• Firewalls
• Encryption
• Access control lists
• Security patches

Real-World Example

A firewall blocks malicious traffic before it reaches a server.

Deterrent Controls

Purpose

Discourage of attacks.
The control may not stop an attack but makes attackers think twice.

Examples

• Warning signs
• Security guards
• Cameras
• Alarm systems

Real-World Example

Criminals often avoid facilities with visible monitoring systems.

Detective Controls

Purpose

Identify attacks that occur or have occurred.

Examples

• Intrusion Detection Systems (IDS)
• Security logs
• SIEM solutions
• CCTV recordings

Real-World Example

Microsoft Sentinel detects repeated failed login attempts and generates an alert.

Corrective Controls

Purpose

Restore systems after an incident.

Examples

• Malware removal
• Backup restoration
• Patch deployment
• Disaster recovery plans

Real-World Example

A company restores encrypted files after a ransomware attack using backups.

Compensating Controls

Purpose

Provide alternative protection when the preferred control cannot be implemented.

Examples

• Additional monitoring
• VPN-only access
• Manual approvals

Real-World Example

A legacy application cannot support MFA.

Compensating controls:

• VPN access only
• Restricted access hours
• Increased monitoring

Directive Controls

Purpose

Provide instructions and guidance.

Examples

• Security policies
• Procedures
• Standards
• Acceptable Use Policies

Real-World Example

A corporate password policy requiring:
• Minimum 12 characters
• Complexity requirements
• Regular reviews

4. Remembering PDDCCD

Security+ Memory Aid

Letter Control Type Purpose
P Preventive Stop Attacks
D Deterrent Discourage attacks
D Detective Detect Attacks
C Corrective Recover from attacks
C Compensating Alternative protection
D Directive Provide guidance

Key Takeaways

  • Security controls reduce organizational risk.
  • Defense in Depth uses multiple security layers.
  • Four categories of controls:
    • Technical
    • Managerial
    • Operational
    • Physical
  • Six common control types:
    • Preventive
    • Deterrent
    • Detective
    • Corrective
    • Compensating
    • Directive
  • One control can belong to multiple control types.
  • Security+ examinations frequently test control categories and PDDCCD classifications
