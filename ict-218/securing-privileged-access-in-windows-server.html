1. Why Identity Is the Primary Target

Modern cyberattacks are usually focused on obtaining credentials rather than
immediately stealing data.
Once attackers obtain privileged credentials, they can often gain access to systems,
applications, and sensitive information throughout the organization.

Typical Attack Path

Why Credentials Matter

A stolen administrator account may allow an attacker to:
• Create new user accounts
• Reset passwords
• Access sensitive systems
• Disable security tools
• Deploy malware or ransomware
For this reason, identity protection is one of the most important aspects of
cybersecurity.

2. Understanding LSASS

What Is LSASS?

https://learn.microsoft.com/en-us/security/privileged-access-workstations/privileged-access-access-model

LSASS stands for:
Local Security Authority Subsystem Service
LSASS is a Windows process responsible for:

  • User authentication
  • Security policy enforcement
  • Kerberos processing
  • Access token generation
    • the thing that keeps you signed in

Authentication Process


After a successful login, Windows creates an access token containing:

  • User identity information
  • Security identifiers (SIDs)
  • Group memberships
  • Assigned permissions
    The operating system uses this token to determine what resources a user can
    access.

Why Attackers Target LSASS

Historically, LSASS stored:

  • NTLM hashes
  • Kerberos tickets
  • Authentication secrets
    Attackers attempt to read LSASS memory to collect these credentials


Many credential theft attacks rely on obtaining information stored in LSASS memory.

3. Credential Guard

Why Credential Guard Exists

How Credential Guard works | Microsoft Learn

Microsoft recognized that credentials stored within normal operating system memory
could be targeted by malware.

Credential Guard was designed to isolate and protect authentication secrets.

Technologies Used

Credential Guard relies on:

  • Virtualization-Based Security (VBS)
  • Hypervisor protection
  • Secure Boot
  • Trusted Platform Module (TPM)

Traditional Architecture

Before Credential Guard:


If an attacker gained sufficient privileges, credential dumping was possible.

Credential Guard Architecture

Credential Guard stores sensitive information inside an isolated environment.

LSAIso.exe

Credential Guard introduces a protected process called:
LSAIso.exe

LSAIso stores credential information inside a virtualized security boundary that is
protected from normal operating system processes.

Even if malware gains local administrative privileges, accessing credentials becomes
significantly more difficult.

Benefits of Credential Guard

• Protects NTLM hashes
• Protects Kerberos tickets
• Reduces credential theft risks
• Helps prevent lateral movement attacks
• Increases attacker workload

4. Credential Guard Limitations

Credential Guard is a powerful security feature, but it is not a complete security
solution.
It protects stored credentials, but it does not stop all attack methods.

Credential Guard Does Not Prevent

• Phishing attacks
• Keyloggers
• Social engineering
• User mistakes

Example

Suppose a user receives a fake Microsoft 365 login page.
The user enters:
• Username
• Password
The attacker now possesses valid credentials.
Credential Guard cannot prevent this because the user voluntarily supplied the
information.

Key Lesson

Technology alone cannot protect an organization.
Effective security requires:
• Technical controls
• User awareness
• Security policies
• Continuous monitoring

5. Privileged Access Workstations (PAWs)

What Is a PAW?

A Privileged Access Workstation (PAW) is a dedicated device used exclusively for
administrative tasks.
Securing privileged access Enterprise access model - Privileged access | Microsoft Learn
PAWs are designed to reduce exposure to threats that commonly affect everyday user devices.

Why PAWs Are Needed

Consider the following question:
Should a Domain Administrator browse social media and manage Active Directory from the same computer?
Microsoft recommends No.
The security of administrative accounts should not depend on the security of normal web browsing activities.

Poor Practice

Better Practice

Security Features Commonly Found on PAWs

  • BitLocker
  • Secure Boot
  • TPM
  • Credential Guard
  • Application Control
  • Multi-Factor Authentication (MFA)

Benefits

PAWs help:

  • Reduce credential theft
  • Limit malware exposure
  • Protect privileged accounts
  • Improve administrative security

6. Administrative Tiering

Administrative Tiering separates systems into different trust levels. The goal is to prevent attackers from moving easily between system.

Tier 0

Tier 0 contains identity infrastructure.

Examples include:

• Domain Controllers
• Active Directory
• Public Key Infrastructure (PKI)
• Authentication Services

Important

If Tier 0 is compromised, the organization is effectively compromised.
Think of Tier 0 As the organization's:
• Identity control plane
• Security foundation
• Administrative core

Tier 1

Tier 1 contains business services.

Examples:

• File Servers
• Database Servers
• Application Servers
• Hyper-V Hosts

These systems support business operations but do not directly control organizational identities

Tier 2

Tier 2 consists of user devices.

Examples:

• Desktops
• Laptops
• Help Desk workstations

Tier 2 devices are typically the most exposed to:
• Malware
• Phishing
• User-generated risks

7. Clean Source Principle

The Clean Source Principle is one of the most important concepts in privileged access security.

Principle

Administrative activity should originate only from devices that are equally or more
trusted than the systems being managed.

Good Example

Bad Example

Key Rule

Never manage a higher-trust system from a lower-trust device.

Trust must flow from high to high, not low to high.

Following this principle significantly reduces the risk of administrative credential
compromise.

8. LAPS Review

Although today's primary focus is Credential Guard and Privileged Access Security, LAPS remains an important component of Microsoft's security strategy.

What Is LAPS?

LAPS stands for: Local Administrator Password Solution
Its purpose is to automatically manage local administrator passwords on Windows systems.

Traditional Approach

Many organizations historically used the same local administrator password on
multiple computers.

Example


If an attacker compromises one computer, the password may work everywhere.

LAPS Approach

LAPS automatically creates unique passwords for each device.

Benefits:

• Unique passwords
• Automatic rotation
• Reduced lateral movement
• Improved security

Module Summary

Microsoft's privileged access strategy combines multiple technologies to protect
identities and administrative accounts.

Credential Guard

Protects:
• NTLM hashes
• Kerberos tickets
• Authentication secrets

PAWs

Protect:
• Administrative activities
• Highly privileged accounts

Administrative Tiering

Protects:
• Identity infrastructure
• Trust boundaries
• Critical services

LAPS

Protects:
• Local administrator accounts
• Endpoint passwords

Final Takeaway

Attackers target identities because identities provide access. Protecting credentials, administrators, and trust boundaries is essential to securing modern Windows Server 2025 environments
