Deception Technologies

Definition

Deception technologies intentionally attract attackers to detect and study malicious
activity.
They provide early warnings of threats while collecting intelligence.

simply

simply put its a diversion and an early warning system.

Honeypot

Definition

A decoy system designed to attract attackers.

Purpose

  • Detect attackers
  • Study attack techniques
  • Divert threats

Honeynet

Definition

A network of interconnected honeypots or aa diversion network.

Purpose

Simulate an entire environment.

Benefit

Provides deeper threat intelligence than a single honeypot.

Honeyfile

Definition

A fake document designed to trigger alerts when opened.

Example

Payroll_Executives.xlsx
No legitimate employee should access it.

If opened:

  • Security teams receive an alert.

Honeytoken

Definition

A fake credential or data item used to detect unauthorized access.

Examples

• Fake passwords
• Fake API keys
• Fake database accounts

Real-World Case Study

A cloud administrator creates fake AWS credentials and places them in a repository.
If someone attempts to use them:

  • The organization immediately knows credentials were stolen.
  • Security personnel can investigate
