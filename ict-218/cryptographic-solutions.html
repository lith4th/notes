Cryptographic Solutions

Preamble - What Is Cryptography?

Cryptography is the science of protecting information by converting readable data (plaintext) into unreadable data (ciphertext) so that only authorized users can access it. Cryptography helps organizations protect confidentiality, integrity, authentication, and non-repudiation. CompTIA Security+ SY0-701 Cert Guide and CompTIA Security+ SY0-701 Exam Cram, 7th Edition identify cryptography as a core Security+ domain.

Main Goal of Cryptography

Cryptography provides:

  1. Confidentiality – Prevent unauthorized disclosure of information.
  2. Integrity – Ensure data is not altered.
  3. Authentication – Verify identity.
  4. Non-Repudiation – Prevent denial of an action or transaction

CIA Triad

1. Public Key Infrastructure (PKI)

Definition

Public Key Infrastructure (PKI) is a framework that manages encryption keys and digital certificates to establish trust between users, devices, and services.

Purpose

PKI allows secure communications across untrusted networks such as the Internet.

Components of PKI

Certificate Authority (CA)
A trusted organization that issues and validates digital certificates.

Examples:

• DigiCert
• GlobalSign
• Let's Encrypt

Registration Authority (RA)
Verifies the identity of users before certificates are issued.

Certificate Repository
Stores certificates for public access.

2. Public Key and Private Key

Public Key

Definition

A key that can be distributed publicly and is used for:
• Encryption
• Signature verification

Example

A company web server publishes its public key through its SSL certificate.

Private Key

Definition

A secret key known only to the owner.
Used for:
• Decryption
• Creating digital signatures

Security Rule

Private keys must never be shared.

3. Key Exchange

Definition

A secure method used by communicating parties to exchange encryption keys.

Why Important?

Without secure key exchange:
• Attackers may steal session keys.
• Encrypted communication becomes vulnerable.

Examples

• Diffie-Hellman (DH)
• Elliptic Curve Diffie-Hellman (ECDHE)

4. Key Length

Definition

Key length refers to the number of bits within an encryption key.

Principle

Longer keys increase the amount of work required to crack the encryption.

Examples

• DES = 56-bit
• AES-128 = 128-bit
• AES-256 = 256-bit
• RSA-2048 = 2048-bit

Exam Tip

"Key Length = Work Factor"
The larger the key, the harder it is to break.

5. Symmetric Encryption

Definition

Uses the same key to encrypt and decrypt information.

Process

Advantages

• Fast
• Efficient
• Suitable for large volumes of data

Disadvantages

• Key distribution challenge

AES (Advanced Encryption Standard)

Definition

The most widely used symmetric encryption standard.

Common Uses

• BitLocker
• VPNs
• Wireless networks
• Database encryption

Real-World Example

Windows BitLocker uses AES to protect lost or stolen laptops.

6. Asymmetric Encryption

Definition

Uses two mathematically related keys:
• Public Key
• Private Key

Process

  • Public Key Encrypts
  • Private Key Decrypts

Advantages

• Supports authentication
• Enables digital signatures
• Solves key sharing problem

Disadvantages

• Slower than symmetric encryption

RSA

Definition

A common asymmetric encryption algorithm used in:
• HTTPS
• Certificates
• Digital signatures

7. Data-at-Rest Encryption

Data at rest means data stored on a device.

Full Disk Encryption (FDE)

Definition

Encrypts an entire drive.

Example

BitLocker

Protects Against

• Lost laptops
• Stolen hard drives

Partition Encryption

Definition

Encrypts a specific disk partition.

Volume Encryption

Definition

Encrypts a logical storage volume.

File Encryption

Definition

Encrypts individual files.

Example

Encrypting confidential HR documents.

Database Encryption

Definition

Encrypts all information stored in a database.

Record Encryption

Definition

Encrypts selected records inside a database.

Example

Encrypt only SIN or credit card fields.

8. Hashing

Definition

Hashing transforms data into a fixed-length value called a hash.

Important

Hashing is NOT encryption.
Hashes cannot be reversed.

Purposes

  • Integrity Verification
    • Detect file modification.
  • Password Storage
    • Stores passwords securely.
  • Digital Signatures
    • Creates message digest.

SHA-256

Definition

A secure hashing algorithm commonly used today.

Real-World Example

Microsoft publishes file hashes for software verification.

9. Salting

Definition

Random data added to a password before hashing.

Purpose

Protects against:

  • Rainbow table attacks
  • Precomputed hash attacks

Example


Two users with the same password will have different hashes.

10. Key Stretching

Definition

Increases hashing complexity to make password cracking slower.

Technologies

• PBKDF2
• bcrypt
• scrypt
• Argon2

Purpose

Makes brute-force attacks significantly harder.

11. Digital Signatures

Definition

A cryptographic method that proves:

  1. Sender identity
  2. Integrity
  3. Non-repudiation

How It Works


Recipient verifies using sender's public key.

Real-World Example

Microsoft digitally signs Windows updates.

12. Certificates

Definition

A digital document that associates an identity with a public key.

Certificate Contains

• Subject Name
• Public Key
• Issuer
• Serial Number
• Expiration Date
• Digital Signature

Certificate Signing Request (CSR)

Definition

A request submitted to a CA for a new certificate.

Self-Signed Certificate

Definition

A certificate created and signed by the same organization using it.

Advantage

Free

Disadvantage

Not trusted automatically.

Wildcard Certificate

Definition

Protects multiple subdomains using one certificate.

Example

google.com

Protects:
• www.google.com
• accounts.google.com

13. Certificate Revocation

Sometimes certificates become compromised and must be revoked.

CRL (Certificate Revocation List)

Definition

A list of revoked certificates maintained by a CA.

Limitation

May not always contain real-time information.

OCSP (Online Certificate Status Protocol)

Definition

Provides real-time certificate validation.

Advantage

More current than CRLs.

14. TPM (Trusted Platform Module)

Definition

A hardware security chip that stores cryptographic keys securely.

Uses

• BitLocker
• Secure Boot
• Windows Hello

Benefit

Keys are stored in hardware rather than software.

15. HSM (Hardware Security Module)

Definition

A specialized security appliance that protects highly sensitive cryptographic keys.

Common Uses

• Banks
• Cloud providers
• Certificate Authorities

Benefit

Provides the highest level of key protection.

16. Tokenization

Definition

Replaces sensitive data with a non-sensitive token.

Example

Credit Card:
4111-2222-3333-4444
Becomes
TKN-98A7F32

Benefit

Original data is removed from systems.

17. Data Masking

Definition

Conceals portions of sensitive information while preserving usability.

Example

SIN:
123-456-789
Displayed:
XXX-XXX-789

18. Steganography

Definition

The practice of hiding information inside another file.

Examples

• Hiding text in an image
• Hiding information in audio files
• Embedding data inside videos

Difference from Encryption

Encryption hides meaning.
Steganography hides existence.

19. Blockchain

Definition

A distributed ledger that stores data in cryptographically linked blocks.

Characteristics

• Decentralized
• Immutable
• Tamper-resistant
• Transparent

Uses

• Cryptocurrency
• Smart contracts
• Supply chain tracking

Real-World Case Study: HTTPS Connection

When a student visits Brightspace or online banking:

  1. The server presents its certificate.
  2. The browser validates the certificate using the CA.
  3. Public key cryptography establishes trust.
  4. Symmetric AES encryption secures the communication session.
  5. Hashing verifies data integrity.
  6. Digital signatures verify authenticity.
    This demonstrates PKI, certificates, encryption, hashing, and digital signatures
    working together to protect internet communications.

Chapter 4 Exam Review

Remember the following:

  • AES (Advanced Encryption Standard) = Symmetric Encryption
  • RSA (Rivest–Shamir–Adleman)= Asymmetric Encryption
  • SHA-256 (Secure Hash Algorithm) = Hashing
  • PKI (Public Key Infrastructure )= Trust Framework
  • CA (Certificate Authorities) = Issues Certificates
  • CSR (Certificate Signing Request) = Certificate Request
  • Digital Signature = Integrity + Authentication + Non-Repudiation
  • TPM (Trusted Platform Module )= Secure Key Chip
  • HSM (Hardware security Module )= Enterprise Key Protection
  • Salt = Protect Password Hashes
  • OCSP(Online Certificate Status Protocol) = Real-Time Certificate Checking
  • CRL = Revoked Certificate List
  • Tokenization = Replace Sensitive Data
  • Data Masking = Hide Sensitive Data

Key Takeaway

Cryptography is the foundation of modern cybersecurity. Security professionals must choose the correct cryptographic solution based on the objective: confidentiality (encryption), integrity (hashing), authentication (certificates), or non-repudiation (digital signatures).
